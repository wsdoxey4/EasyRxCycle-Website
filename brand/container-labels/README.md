# Container Labels (print-ready)

`EasyRxCycle_Container_Labels.zip` — the 8 waste-stream container labels, print-ready
(3.16×4 in trim + 0.125 in bleed + crop marks): Sharps, Biohazard, Pharmaceutical,
Controlled, RCRA, Trace Chemo, Medication Disposal Kit, Activated Charcoal.

Not web-served (lives outside `public/`); stored here for version control.
